# Cold Chain Indicator and Monitoring Tag

## 📌 Project Overview
The Cold Chain Indicator and Monitoring Tag is an IoT-based system designed to monitor the condition of medicine boxes during transportation. It uses sensors to check temperature, humidity, shock, vibration, tampering, and water exposure. The system helps identify unsafe conditions and supports the safe transportation of medicines and vaccines.

## 🎯 Objectives
- Monitor the condition of medicine boxes.
- Detect temperature and humidity changes.
- Identify shock, vibration, and tampering.
- Detect water exposure.
- Provide real-time sensor information.
- Improve medicine safety during transportation.

## 🛠️ Technologies Used
- **Controller:** ESP8266 NodeMCU
- **Sensors:** DHT11, MPU6050, Magnetic Tamper Switch, Water Sensor
- **Programming Languages:** C/C++, HTML, CSS, JavaScript
- **IoT Platform:** Blynk IoT
- **Tools:** Arduino IDE, VS Code, GitHub

## ⚙️ Key Features
- Temperature monitoring
- Humidity monitoring
- Shock and vibration detection
- Box tamper detection
- Water detection
- Live sensor data monitoring
- Sender and Receiver dashboards
- Shipment condition monitoring

## 🔄 Working Process
1. Sensors collect data from the medicine box.
2. ESP8266 processes the sensor readings.
3. Data is transmitted through Wi-Fi.
4. Blynk IoT displays the sensor values.
5. The web dashboard helps users monitor the box condition.
